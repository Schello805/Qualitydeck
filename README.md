# DIN EN ISO 9001:2015 - Audit & Management App

Diese Web-Anwendung dient Qualitätsmanagementbeauftragten (QMB) als digitales Werkzeug, um die Einhaltung der Normanforderungen der DIN EN ISO 9001:2015 zu prüfen, zu dokumentieren und pro Abteilung nachzuweisen.

## 🚀 Features

- **Abteilungsverwaltung:** Stammdaten für unterschiedliche Abteilungen pflegen.
- **Normkatalog (Kapitel 5-10):** Vorgefertigter, aber anpassbarer Fragenkatalog für die wichtigsten Anforderungen der High Level Structure.
- **Audit-Durchführung:** Dokumentation der Umsetzung pro Abteilung.
- **Nachweis-Upload:** Anhängen von Dokumenten, PDFs und Bildern (via Firebase Storage) oder Verlinken von Dateien.
- **Dashboard:** Übersicht über den Erfüllungsgrad.

## 🛠 Technologie-Stack

- **Frontend:** Next.js (React), TailwindCSS
- **Backend & Datenbank:** Firebase (Auth, Firestore, Cloud Storage)
- **Deployment:** Vercel oder Firebase Hosting
